# ERP Suite — Preview

Two client-facing documents for the CTOP ERP Suite, served with GitHub Pages.

| File | What it is |
|---|---|
| `index.html` | Landing page linking to both documents |
| `ERP-Blueprint.html` | The system explained in plain language, section by section |
| `ERP-Prototype.html` | Clickable prototype — every screen, EN/AR, light/dark |

The prototype is a demonstration. It holds sample data, saves nothing, and resets on reload.

Search engines are asked not to index this site (`robots.txt` + `noindex`), but the pages are
reachable by anyone who has the link.
